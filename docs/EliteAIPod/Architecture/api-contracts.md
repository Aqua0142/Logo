### POST `/api/v1/auth/login`

Validates email/password credentials against the users table. Verifies the password hash using Argon2. On success, inserts a session record and returns a signed JWT containing user_id and role. Returns 401 with a generic error message on invalid credentials to prevent user enumeration.

**Status codes:** `200` Login successful, JWT returned, `401` Invalid credentials, `422` Request validation error_Related stories: US-001_
### POST `/api/v1/auth/logout`

Removes the session token from the sessions table (or adds to a denylist), ensuring that a reused token after logout returns 401. The JWT is extracted from the Authorization header.

**Status codes:** `200` Session invalidated successfully, `401` Token missing or already invalidated_Related stories: US-002_
### POST `/api/v1/blood-work`

Accepts a JSON body with patient_id, test_name, value, units, collected_at. Validates all fields including numeric precision for value and existence of patient_id. Persists to blood_work_results. Returns 403 if caller is not a Lab Technician.

**Required role:** lab_technician**Status codes:** `201` Blood work record created, `403` Forbidden — caller is not a Lab Technician, `404` patient_id does not exist, `422` Validation error with field-level details_Related stories: US-005, US-006_
### GET `/api/v1/blood-work/my-results`

Extracts patient_id from the authenticated JWT. Queries blood_work_results joined with reference_ranges to return test results with computed is_out_of_range boolean. Returns 403 if caller is not a Patient. Returns empty array with 200 when no results exist. Target response time <500ms.

**Required role:** patient**Status codes:** `200` Results returned (empty array if none), `403` Forbidden — caller is not a Patient, `500` Internal server error with user-friendly message_Related stories: US-007_
