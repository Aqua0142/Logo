## Architecture Pattern

**Pattern:** modular_monolith

A modular monolith is the optimal pattern for this small-scale internal prototype serving fewer than 50 concurrent users. It provides clear module boundaries (auth, blood-work, users) without the operational overhead of microservices — no inter-service networking, no distributed tracing, no separate deployments. PostgreSQL with server-side encryption satisfies the HIPAA-adjacent PHI requirements at rest, while FastAPI provides async performance for the sub-500ms API response time NFR. A single deployable unit simplifies the CI/CD pipeline and reduces infrastructure costs during the prototype phase, while the modular internal structure ensures the codebase can be decomposed into microservices later if scale demands it.

## Infrastructure

- **Deployment:** Single-host Docker Compose deployment for the prototype: FastAPI backend container, React SPA served via Nginx container, and PostgreSQL 16 container. TLS 1.3 terminated at Nginx with a self-signed certificate for internal use. Environment variables injected via .env file; never committed to source control.
- **Scaling:** Vertical scaling sufficient for prototype load (<50 concurrent users). For future growth: horizontal FastAPI replicas behind Nginx upstream load balancing, PostgreSQL read replicas for the my-results query path, and connection pooling via PgBouncer.
- **Caching:** none

## Security Considerations

- All passwords hashed with Argon2id (memory=65536, iterations=3, parallelism=4) — never stored in plaintext
- JWTs signed with HS256 using a 256-bit secret from environment variable; include jti claim for server-side invalidation
- Every protected endpoint validates JWT and enforces role claim before any business logic executes
- PHI fields (patient_id FK, blood work values) encrypted at rest using AES-256 via SQLAlchemy TypeDecorator with encryption key stored in environment variable
- TLS 1.3 enforced in transit via Nginx for all API and SPA traffic
- 401 responses use a generic 'Invalid credentials' message to prevent user enumeration attacks
- 403 responses returned immediately when role does not match required_role — no data leakage
- CORS policy restricts API access to the known SPA origin only
- Secrets never committed to source control; .env.example contains placeholder values only
- Session tokens invalidated server-side on logout; subsequent requests with reused tokens return 401
